## 一、隐式转换速查总结表

### ToNumber 转换结果

| 输入值 | ToNumber 结果 | 说明 |
|:---|:---:|:---|
| `undefined` | `NaN` | 规范明确定义 |
| `null` | `0` | 规范明确定义 |
| `true` | `1` | |
| `false` | `0` | |
| `''` | `0` | 空字符串 |
| `'123'` | `123` | |
| `'123abc'` | `NaN` | 含非数字字符 |
| `'0x1F'` | `31` | 十六进制 |
| `[]` | `0` | ToPrimitive → `''` → `0` |
| `[1]` | `1` | ToPrimitive → `'1'` → `1` |
| `[1,2]` | `NaN` | ToPrimitive → `'1,2'` → NaN |
| `{}` | `NaN` | ToPrimitive → `'[object Object]'` → NaN |
| `Symbol()` | ❌ TypeError | 不能转换 |
| `1n`（BigInt） | ❌ TypeError | 不能隐式转换 |

### ToBoolean 转换（假值完整列表）

| 值 | ToBoolean |
|:---|:---:|
| `false` | false |
| `0` | false |
| `-0` | false |
| `0n` | false |
| `''`（空字符串） | false |
| `null` | false |
| `undefined` | false |
| `NaN` | false |
| 其他所有值 | **true** |

### `==` 的转换规则优先级

| 场景 | 转换规则 |
|:---|:---|
| `null == undefined` | true（特殊规则，只有这一对）|
| `Boolean == 其他` | Boolean → `ToNumber` → 递归 |
| `Number == String` | String → `ToNumber` → 比较 |
| `Object == 原始值` | Object → `ToPrimitive` → 递归 |
| 其他组合 | `false` |

## 二、工程陷阱案例

### 陷阱 1：`[] + {}` vs `{} + []` 的上下文之谜

```javascript
// 在 Node.js REPL 或 Chrome Console 中直接输入：
[] + {}   // '[object Object]'（表达式语句，[] 先求值）
{} + []   // 0 （{} 被解析为空代码块！+[] 是一元正号）

// 在代码文件中（表达式上下文）：
const a = [] + {};   // '[object Object]' ✅
const b = {} + [];   // '[object Object]' ✅（此时 {} 是对象字面量）
console.log({} + []); // '[object Object]' ✅（括号中强制表达式上下文）
```

**根本原因**：`{` 在语句开头时被 JS 引擎解析为代码块，而非对象字面量。这是文法歧义（Grammar Ambiguity）问题。

**工程规范**：ESLint `no-unused-expressions` 规则可以防止此类歧义。

### 陷阱 2：`parseInt` 与 `Array.map` 的隐式参数传递

```javascript
// 看似合理的代码
const nums = ['1', '2', '3', '4', '5'];

// ❌ 错误写法（高频坑）
const result = nums.map(parseInt);
console.log(result); // [1, NaN, NaN, NaN, NaN]

// 原因分析：
// Array.map 调用 callback(element, index, array)
// 所以 parseInt 接收到：
// parseInt('1', 0)  → 0 作为 radix，特殊处理，当做十进制 → 1
// parseInt('2', 1)  → radix=1 不合法 → NaN
// parseInt('3', 2)  → radix=2（二进制），'3' 不是合法二进制数 → NaN
// parseInt('4', 3)  → radix=3（三进制），'4' 不合法 → NaN
// parseInt('5', 4)  → radix=4（四进制），'5' 不合法 → NaN

// ✅ 正确写法
const result2 = nums.map(Number);           // [1, 2, 3, 4, 5]
const result3 = nums.map(s => parseInt(s, 10)); // [1, 2, 3, 4, 5]
```

### 陷阱 3：比较运算中的字符串排序

```javascript
// 接口返回的数据（字符串格式）
const scores = ['10', '9', '100', '2', '20'];

// ❌ 错误：直接排序（字典序）
console.log(scores.sort());
// ['10', '100', '2', '20', '9']  ← 字典序，不是数值序！

// ❌ 错误：直接比较
console.log('10' > '9');    // false（字典序：'1' < '9'）
console.log('10' > 9);      // true（'10' 转 Number → 10 > 9）

// ✅ 正确：显式转换后排序
console.log(scores.sort((a, b) => Number(a) - Number(b)));
// ['2', '9', '10', '20', '100'] ✅
```

### 题目 1：逐步追踪 `[] == ![]` 的计算过程

**要求**：一步一步写出规范算法，解释最终结果为 `true` 的原因。

**完整答案**：

```
原始表达式：[] == ![]

=== 第一步：计算右侧 ![] ===

![] 使用逻辑非运算符，步骤：
1. ToBoolean([]) → [] 是对象，非假值 → true
2. !true → false

所以表达式变为：[] == false

=== 第二步：应用 Abstract Equality Comparison ===

[] == false

规则检查：
- Type([]) = Object，Type(false) = Boolean
- 匹配规则：Type(y) 是 Boolean → ToNumber(y)，递归
- ToNumber(false) = 0

表达式变为：[] == 0

=== 第三步 ===

[] == 0

规则检查：
- Type([]) = Object，Type(0) = Number
- 匹配规则：Type(x) 是 Object，Type(y) 是 Number → ToPrimitive(x)，递归
- ToPrimitive([])：
  - 尝试 [].valueOf() → [] 本身（非原始值）
  - 尝试 [].toString() → ''（原始值！）
- ToPrimitive([]) = ''

表达式变为：'' == 0

=== 第四步 ===

'' == 0

规则检查：
- Type('') = String，Type(0) = Number
- 匹配规则：Type(x) 是 String，Type(y) 是 Number → ToNumber(x)，递归
- ToNumber('') = 0

表达式变为：0 == 0

=== 第五步 ===

0 == 0

- 两者类型相同（Number）
- 使用严格相等：0 === 0 → true

最终结果：[] == ![] → true ✅
```

### 题目 2：实现 `safeEquals` 函数，完全杜绝隐式转换

**要求**：实现一个严格的相等比较函数，对任何类型的值都给出精确结果，包括处理 `NaN`、`-0/+0`、`null/undefined` 等特殊情况。

```javascript
/**
 * 精确相等比较，无任何隐式转换
 * - NaN === NaN（不同于 ===）
 * - +0 !== -0（不同于 ===）
 * - null !== undefined（不同于 ==）
 */
function safeEquals(a, b) {
  // 使用 Object.is 语义：
  // Object.is(NaN, NaN) = true
  // Object.is(+0, -0) = false
  return Object.is(a, b);
}

// 扩展版：支持深度比较
function deepEquals(a, b, visited = new Map()) {
  // 处理原始值（含 NaN 和 ±0）
  if (Object.is(a, b)) return true;

  // 类型不同直接返回 false
  if (typeof a !== typeof b) return false;
  if (typeof a !== 'object' && typeof a !== 'function') return false;
  if (a === null || b === null) return false;

  // 循环引用检测
  if (visited.has(a)) return visited.get(a) === b;
  visited.set(a, b);

  // 数组比较
  if (Array.isArray(a) !== Array.isArray(b)) return false;
  if (Array.isArray(a)) {
    if (a.length !== b.length) return false;
    return a.every((v, i) => deepEquals(v, b[i], visited));
  }

  // 普通对象比较
  const keysA = [...Object.keys(a), ...Object.getOwnPropertySymbols(a)];
  const keysB = [...Object.keys(b), ...Object.getOwnPropertySymbols(b)];
  if (keysA.length !== keysB.length) return false;

  return keysA.every(key => deepEquals(a[key], b[key], visited));
}

// 测试
console.log(safeEquals(NaN, NaN));       // true（Object.is 语义）
console.log(safeEquals(+0, -0));         // false（Object.is 语义）
console.log(safeEquals(null, undefined)); // false（不同类型）

console.log(deepEquals([1, 2, NaN], [1, 2, NaN])); // true
console.log(deepEquals({a: 1}, {a: 1}));           // true
console.log(deepEquals({a: +0}, {a: -0}));          // false（精确！）
```

### 题目 3：设计支持 `[Symbol.toPrimitive]` 的 `Money` 类

**要求**：实现一个货币类，使其能在字符串模板、数学运算、比较中自然使用。

```javascript
class Money {
  #amount;
  #currency;

  constructor(amount, currency = 'CNY') {
    if (typeof amount !== 'number' || !Number.isFinite(amount)) {
      throw new TypeError('amount 必须是有限数字');
    }
    this.#amount = Math.round(amount * 100); // 存储为分（避免浮点误差）
    this.#currency = currency;
  }

  get amount() {
    return this.#amount / 100;
  }

  add(other) {
    if (!(other instanceof Money)) throw new TypeError('只能与 Money 相加');
    if (other.#currency !== this.#currency) throw new Error('货币类型不匹配');
    return new Money(this.amount + other.amount, this.#currency);
  }

  [Symbol.toPrimitive](hint) {
    switch (hint) {
      case 'number':
        return this.amount;                         // 数学运算时返回数值
      case 'string':
        return `${this.amount.toFixed(2)} ${this.#currency}`; // 字符串时带单位
      default:
        return this.amount;                         // 默认同 number
    }
  }

  valueOf() {
    return this.amount; // 兼容不支持 Symbol.toPrimitive 的环境
  }

  toString() {
    return `${this.amount.toFixed(2)} ${this.#currency}`;
  }
}

// 使用测试
const price = new Money(19.9);
const discount = new Money(5.0);
const total = price.add(discount);

console.log(`商品总价：${price}`);         // '商品总价：19.90 CNY'（string hint）
console.log(price > 15);                  // true（number hint）
console.log(price + discount);            // 24.9（number hint，+运算符）
console.log(price + ' 元');               // '19.9 元'（string hint，字符串拼接）
console.log(total.amount);               // 24.9（精确，无浮点误差）

// 精度验证
const a = new Money(0.1);
const b = new Money(0.2);
console.log(a.add(b).amount);           // 0.3（精确！）
```

### 题目 4：写出下列代码的输出，并解释原因

```javascript
// 题目代码
console.log(1);
console.log([] + []);
console.log({} + []);
console.log([] + {});
console.log(+[]);
console.log(+{});
console.log(+null);
console.log(+undefined);
console.log(+true);
console.log(+'');
console.log(+' ');
console.log(+'3.14');
```

**完整答案**：

```javascript
console.log(1);            // 1
console.log([] + []);      // ''     ('' + '' = '')
console.log({} + []);      // '[object Object]'  (在表达式中，{} 是对象)
console.log([] + {});      // '[object Object]'  ('' + '[object Object]')
console.log(+[]);          // 0      (ToNumber(ToPrimitive([])) = ToNumber('') = 0)
console.log(+{});          // NaN    (ToNumber('[object Object]') = NaN)
console.log(+null);        // 0      (ToNumber(null) = 0)
console.log(+undefined);   // NaN   (ToNumber(undefined) = NaN)
console.log(+true);        // 1      (ToNumber(true) = 1)
console.log(+'');          // 0      (ToNumber('') = 0)
console.log(+' ');         // 0      (去除空白后为 '' → 0)
console.log(+'3.14');      // 3.14
```
