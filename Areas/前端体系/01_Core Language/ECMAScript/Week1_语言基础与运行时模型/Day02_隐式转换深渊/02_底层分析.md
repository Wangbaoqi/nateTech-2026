## 一、ToPrimitive 算法（Clause 7.1.1）

`ToPrimitive(input [, preferredType])` 是所有隐式转换的核心入口，将对象转换为原始值。

### 1.1 完整算法步骤

```
ToPrimitive(input, preferredType):

1. 如果 input 是原始值 → 直接返回 input（无需转换）

2. 确定 hint：
   - preferredType 为 string → hint = "string"
   - preferredType 为 number → hint = "number"
   - preferredType 未提供（即 default）→ hint = "default"
   
   ⚠️ 注意：Date 对象重写此步骤，将 "default" 视为 "string"！

3. 如果对象有 [Symbol.toPrimitive] 方法：
   a. 调用 input[Symbol.toPrimitive](hint)
   b. 结果如果是原始值 → 返回结果
   c. 否则 → 抛出 TypeError

4. 如果 hint 是 "default" → hint = "number"（除 Date 外）

5. 调用 OrdinaryToPrimitive(input, hint)
```

### 1.2 OrdinaryToPrimitive 算法

```
OrdinaryToPrimitive(O, hint):

1. 如果 hint 是 "string"：
   methodNames = ["toString", "valueOf"]
   
2. 如果 hint 是 "number"：
   methodNames = ["valueOf", "toString"]

3. 依次尝试 methodNames 中的方法：
   for each name in methodNames:
     method = O[name]
     if method 是可调用的（函数）:
       result = method.call(O)
       if result 是原始值: return result
       
4. 抛出 TypeError（无法转换为原始值）
```

**具体追踪：`[] + {}`**

```javascript
// 步骤追踪：[] + {}

// 1. 二元 + 运算，hint = "default"
// 2. 先转换左操作数 []
//    ToPrimitive([], "default") → hint = "number"
//    → OrdinaryToPrimitive([], "number")
//      → 尝试 valueOf()：[].valueOf() = [] （非原始值，跳过）
//      → 尝试 toString()：[].toString() = '' （原始值！）
//    结果：''

// 3. 再转换右操作数 {}
//    ToPrimitive({}, "default") → hint = "number"
//    → OrdinaryToPrimitive({}, "number")
//      → 尝试 valueOf()：{}.valueOf() = {} （非原始值，跳过）
//      → 尝试 toString()：{}.toString() = '[object Object]' （原始值！）
//    结果：'[object Object]'

// 4. 两个操作数都是字符串 → 字符串拼接
// 结果：'' + '[object Object]' = '[object Object]'
console.log([] + {}); // '[object Object]' ✅
```

## 二、ToNumber 算法（Clause 7.1.4）

完整的类型到数字的转换分支树：

```
ToNumber(argument):

├── Undefined   → NaN
├── Null        → +0
├── Boolean     → true → 1, false → +0
├── Number      → 不变（identity）
├── String      → 见下方 StringToNumber 算法
├── Symbol      → 抛出 TypeError（不能转数字！）
├── BigInt      → 抛出 TypeError（不能转数字！）
└── Object      → ToPrimitive(argument, "number") 然后递归 ToNumber
```

### 2.1 StringToNumber 算法（Clause 7.1.4.1）

```
String → Number 的规则：
- ""（空字符串）       → +0
- "   "（纯空白）      → +0
- "123"               → 123
- "3.14"              → 3.14
- "0x1F"（十六进制）  → 31
- "0o17"（八进制）    → 15
- "0b1010"（二进制）  → 10
- "Infinity"           → Infinity
- "-Infinity"          → -Infinity
- 其他任何字符串       → NaN
```

```javascript
// 验证
console.log(Number(''));         // 0
console.log(Number('  '));       // 0（去除首尾空白后是空字符串）
console.log(Number('123'));      // 123
console.log(Number('123abc'));   // NaN（有非数字字符）
console.log(Number('0x1F'));     // 31
console.log(Number(null));       // 0
console.log(Number(undefined));  // NaN
console.log(Number(true));       // 1
console.log(Number(false));      // 0
console.log(Number([]));         // 0（ToPrimitive([]) = '' → 0）
console.log(Number([1]));        // 1（ToPrimitive([1]) = '1' → 1）
console.log(Number([1,2]));      // NaN（ToPrimitive([1,2]) = '1,2' → NaN）
console.log(Number({}));         // NaN（ToPrimitive({}) = '[object Object]' → NaN）
```

## 三、Abstract Equality Comparison（Clause 7.2.13）

完整算法（`x == y`）：

```
AbstractEqualityComparison(x, y):

1. 如果 Type(x) === Type(y)：
   → 使用 Strict Equality（===）规则

2. null == undefined → true
   undefined == null → true

3. 如果 Type(x) 是 Number，Type(y) 是 String：
   → ToNumber(y)，然后递归

4. 如果 Type(x) 是 String，Type(y) 是 Number：
   → ToNumber(x)，然后递归

5. 如果 Type(x) 是 BigInt，Type(y) 是 String：
   → StringToBigInt(y)，如果结果是 NaN 返回 false，否则比较

6. 如果 Type(x) 是 Boolean：
   → ToNumber(x)，然后递归

7. 如果 Type(y) 是 Boolean：
   → ToNumber(y)，然后递归

8. 如果 Type(x) 是 String/Number/BigInt/Symbol，Type(y) 是 Object：
   → ToPrimitive(y)，然后递归

9. 如果 Type(x) 是 Object，Type(y) 是 String/Number/BigInt/Symbol：
   → ToPrimitive(x)，然后递归

10. 其他所有情况 → false
```

### 3.1 手动追踪 `[] == false`

这是面试中最常考的隐式转换追踪题：

```
[] == false

步骤 1：Type(false) 是 Boolean
→ 规则 7：ToNumber(false) = 0
→ [] == 0

步骤 2：Type([]) 是 Object，Type(0) 是 Number
→ 规则 9：ToPrimitive([]) = [].toString() = ''
→ '' == 0

步骤 3：Type('') 是 String，Type(0) 是 Number
→ 规则 3：ToNumber('') = 0
→ 0 == 0

步骤 4：同类型，使用严格相等
→ 0 === 0 → true ✅
```

### 3.2 手动追踪 `null == 0`

```
null == 0

规则 2：null == undefined → true（只有这一个特例）
规则 10：null 与 0 不匹配任何规则 → false

所以 null == 0 → false！（很多人以为是 true）
```

### 3.3 手动追踪 `[] == ![]`

这是更复杂的变体：

```
[] == ![]

步骤 0：先计算右侧 ![]
  ![] → ToBoolean([]) = true → !true = false
  所以变成：[] == false

步骤 1~4：同上，[] == false → true

结论：[] == ![] → true ✅（看起来匪夷所思，但完全符合规范）
```

## 四、Date 对象的特殊 ToPrimitive

Date 对象是内置对象中 **唯一** 将 `hint: "default"` 视为 `hint: "string"` 的特例，原因是：

规范在 Date.prototype[Symbol.toPrimitive] 中明确写道：
```
If hint is "default", set hint to "string".
```

这意味着：
```javascript
const date = new Date('2024-01-01');

// hint: default（+ 运算符触发）→ 被 Date 视为 string
date + '';                        // 日期字符串（如 'Mon Jan 01 2024...'）

// hint: number（-、*、/ 运算触发）
+date;                            // 时间戳毫秒数：1704067200000
date - 0;                         // 1704067200000
date * 1;                         // 1704067200000
```

**工程启示**：不要依赖 Date 的隐式转换行为，始终明确调用 `.getTime()` 或 `Date.now()`。

## 五、`+` 运算符的完整规范算法（Clause 13.15.3）

```
加法运算 lval + rval：

1. lprim = ToPrimitive(lval)  // hint: default
2. rprim = ToPrimitive(rval)  // hint: default

3. 如果 Type(lprim) 是 String 或 Type(rprim) 是 String：
   → ToString(lprim) + ToString(rprim)（字符串拼接）

4. 否则：
   → ToNumeric(lprim) + ToNumeric(rprim)（数值加法）
   （若两者类型不同：BigInt + Number → TypeError）
```

这解释了为什么：
```javascript
1 + '2'    // 步骤3：String 存在 → 字符串拼接 → '12'
[] + []    // lprim='', rprim='' → 字符串拼接 → ''
[] + {}    // lprim='', rprim='[object Object]' → '[object Object]'
{} + []    // 在语句位置：{} 是代码块，+[] 是一元+ → 0
({}) + []  // 在表达式：lprim='[object Object]', rprim='' → '[object Object]'
```
