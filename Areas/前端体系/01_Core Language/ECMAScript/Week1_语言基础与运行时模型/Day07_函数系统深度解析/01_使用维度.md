# 函数系统深度解析 - 使用维度

JavaScript 拥有极其灵活多变的函数系统。函数不仅是可执行的代码块，更是**一等公民 (First-class Object)**。本节梳理 4 种主要函数的表现差异以及高级工程运用。

## 1. 四大核心函数形态对比

现代 JS 中，函数被细分为了多个不同的品种。

| 比较维度 | 普通函数 `function(){}` | 箭头函数 `() => {}` | 生成器 `function*(){}` | 异步函数 `async function(){}` |
| :--- | :--- | :--- | :--- | :--- |
| **`this` 绑定** | 动态（基于调用者或 call/bind） | **词法（继承外层作用域）** | 同普通函数 | 同普通函数 |
| **可否作为构造函数**| ✅ 是 (`new` 成功) | ❌ 否 (无 `prototype` 和 `[[Construct]]`) | ❌ 否 | ❌ 否 |
| **`arguments` 对象**| 有 | **无 (使用 Rest 参数代替)** | 有 | 有 |
| **返回值行为** | 显式 return 返回的值 | 显式/隐式返回 | 返回 **Iterator (迭代器对象)** | 返回 **Promise 对象** |
| **中断与恢复执行** | ❌ 否 | ❌ 否 | ✅ 是 (通过 `yield`) | ✅ 是 (隐式通过 `await`) |

## 2. 深入：call / apply / bind 区别与用法

这三个方法挂载于 `Function.prototype`，用于动态改变普通函数的 `this` 指向。

- **`fn.call(context, arg1, arg2...)`**：立即执行 `fn`，使用逐个传入的参数。
- **`fn.apply(context, [arg1, arg2...])`**：立即执行 `fn`，参数以数组形式传递（常用于兼容老代码的参数透传或结合 `Math.max` 使用）。
- **`fn.bind(context, arg1, arg2...)`**：**不立即执行**，而是返回一个新的函数，并永久绑定了指定的 `this` 和部分参数。

```javascript
// bind 经典运用：React 类组件的事件绑定或 setTimeout
const user = {
    name: "Alice",
    greet() {
        console.log(`Hi, I am ${this.name}`);
    }
};

setTimeout(user.greet, 100); // 丢失 this，输出 "Hi, I am undefined"
setTimeout(user.greet.bind(user), 100); // 正确输出
```

## 3. 函数参数高级用法

### 3.1 剩余参数 (Rest Parameters) vs arguments
`arguments` 是一个类数组对象，箭头函数不可用，且在严格模式下行为怪异。现代工程强烈推荐使用 Rest 参数 `...args`。

```javascript
// 老式写法
function sum() {
    // 必须转为真数组才能调用数组方法
    var args = Array.prototype.slice.call(arguments);
    return args.reduce((a, b) => a + b, 0);
}

// 现代优雅写法
const sumModern = (...args) => args.reduce((a, b) => a + b, 0);
```

### 3.2 默认参数边界情况与副作用
默认参数并不是在定义时求值，而是在**函数每次被调用时**才求值。这意味着你可以在默认参数里放置有副作用的函数调用，实现巧妙的逻辑（如“必填参数检查”）。

```javascript
function requiredArg() {
    throw new Error("Missing required argument!");
}

// 如果调用时不传 param，就会触发默认值的函数调用抛错
function submitData(param = requiredArg()) {
    console.log("Submitting:", param);
}

submitData("data"); // OK
submitData(); // Uncaught Error: Missing required argument!
```

## 4. IIFE (立即执行函数表达式) 模式应用

IIFE: Immediately Invoked Function Expression. 
`(function() { /* code */ })();`

在 ES6 块级作用域普及前，IIFE 是创建私有作用域的唯一手段。如今它主要用于：
1. 模块化早期的 UMD (Universal Module Definition) 封装。
2. 内部需要执行异步代码并在顶层立即获得结果（尤其是 CommonJS 或老旧浏览器不支持顶层 await 时）。
3. 构建局部单例或闭包隔离。

```javascript
// 在不支持顶层 await 的环境中
(async () => {
    const data = await fetch('/api/data').then(r => r.json());
    console.log("初始化数据：", data);
})();
```

## 5. Generator 完整指南 (yield / return / throw)

生成器函数提供了一种可以“暂停 (Suspend)”和“恢复 (Resume)”的控制流。

### 5.1 基础运作
```javascript
function* numberGenerator() {
    console.log("start");
    yield 1;
    console.log("middle");
    yield 2;
    console.log("end");
    return 3;
}
const iter = numberGenerator(); // 执行时什么都不打印，返回一个迭代器
console.log(iter.next()); // 打印 "start", 返回 { value: 1, done: false }
console.log(iter.next()); // 打印 "middle", 返回 { value: 2, done: false }
console.log(iter.next()); // 打印 "end", 返回 { value: 3, done: true }
```

### 5.2 双向通信：向 Generator 注入值
`next(val)` 可以将参数回传，作为上一个被挂起的 `yield` 表达式的返回值。

```javascript
function* chatBot() {
    const name = yield "What is your name?";
    yield `Hello ${name}!`;
}
const bot = chatBot();
console.log(bot.next().value);      // "What is your name?"
console.log(bot.next("Jack").value); // "Hello Jack!"
```

### 5.3 `yield*` 委派
通过 `yield*`，可以将控制权转移给另一个可迭代对象（如数组、另一个 Generator）。
```javascript
function* flatGen(arr) {
    for (const item of arr) {
        if (Array.isArray(item)) {
            yield* flatGen(item); // 递归委派
        } else {
            yield item;
        }
    }
}
const res = [...flatGen([1, [2, [3, 4]]])]; // [1, 2, 3, 4]
```
