# 函数系统深度解析 - 实战面试题

这一节是高级面试的重灾区。不仅要求理解各种函数的语义边界，还要求熟练掌握高阶函数的函数式编程手写技巧。

## 1. 经典陷阱：默认参数的先后死区

**题目**：以下代码输出什么？为什么？
```javascript
function bar(x = y, y = 2) {
    return [x, y];
}
console.log(bar()); 
```
**答案与解析**：
抛出 `ReferenceError: Cannot access 'y' before initialization`。
函数参数在解析时存在着类似 `let` 的 **TDZ (暂时性死区)** 机制。参数是从左向右依次求值并绑定的。当给 `x` 赋值默认的 `y` 时，此时词法绑定中已经有了 `y`，但它还未经历初始化阶段。因此直接报错。

## 2. 经典陷阱：arguments 对象不是真数组

**题目**：如何最安全地将 `arguments` 转化为真数组，并且说明为什么不能在箭头函数中使用它？
**解析**：
在 ES6 以前使用 `Array.prototype.slice.call(arguments)`。
在 ES6 以后使用 `Array.from(arguments)` 或解构 `[...arguments]`。

因为箭头函数在词法解析阶段，就不存在属于自己的 `arguments` 绑定，它使用的是其外围普通函数（如果有的话）的 `arguments`。现代代码一律推荐在参数签名处写明 `...args`。

## 3. 核心手写题 (顶级高频重点)

### 3.1 手写：Function.prototype.bind (支持 new)

**题目要求**：
实现一个自定义的 `myBind`。要求：
1. 能够正确绑定传入的 `this`，并支持参数柯里化合并。
2. 核心难点：**返回的绑定函数如果是被 `new` 调用的，原来绑定的 `this` 必须失效，而要指向 `new` 创建的新实例**。这是原生 `bind` 极其重要的规范特性。

**完整答案**：
```javascript
Function.prototype.myBind = function(context, ...args) {
    // 只能绑定函数
    if (typeof this !== 'function') {
        throw new TypeError('Error: Target is not callable');
    }
    
    // 保存原函数的引用
    const self = this;
    
    // 返回一个新函数
    const fBound = function(...innerArgs) {
        // 判断是否是作为构造函数通过 new 调用？
        // 如果是 new，`this` 会指向 fBound 的实例 (this instanceof fBound)
        const isNew = this instanceof fBound;
        
        // 如果是 new 调用，忽略 context 绑定，使用实例自身的 this。
        // 如果是普通调用，绑定到目标 context。
        return self.apply(
            isNew ? this : context, 
            args.concat(innerArgs) // 参数合并
        );
    };
    
    // 为了让 new 创建出的实例能够顺着原型链找到原函数原型上的方法
    // 需要用一个空函数做跳板，链接原型链 (经典寄生组合继承思维)
    function F() {}
    F.prototype = self.prototype;
    fBound.prototype = new F();
    
    return fBound;
};

// --- 测试验证 ---
function Person(name, age) {
    this.name = name;
    this.age = age;
}
Person.prototype.sayHi = function() { console.log(this.name); };

const obj = {};
const BoundPerson = Person.myBind(obj, "Alice");

// 1. 普通调用
BoundPerson(20);
console.log(obj); // {name: "Alice", age: 20} (绑定生效)

// 2. new 调用 (此时绑定的 obj 应该失效)
const instance = new BoundPerson(30);
console.log(instance.name); // "Alice"
console.log(obj.age); // 20 (并未被覆盖为30，说明 obj 未受 new 影响)
instance.sayHi(); // "Alice" (原型链也完好)
```

### 3.2 手写：Generator 运行器 (Async/Await 的底层原理)

**题目要求**：
`async`/`await` 其实就是 `Generator` + `Promise` 的语法糖。请手写一个 `run` 函数，自动推动 yield 出 Promise 的 Generator 跑完。这在老旧前端工程的 co 库中非常著名。

**完整答案**：
```javascript
function runGenerator(genFn) {
    return new Promise((resolve, reject) => {
        const iter = genFn();
        
        // 步进推动函数
        function step(nextFn) {
            let next;
            try {
                // 执行 next() 或 throw()
                next = nextFn();
            } catch (e) {
                return reject(e);
            }
            
            // 如果 Generator 执行完毕，整体 Promise resolve
            if (next.done) {
                return resolve(next.value);
            }
            
            // 否则，将 yield 出来的值包装为 Promise，等它完成后再继续推动下一步
            Promise.resolve(next.value).then(
                val => step(() => iter.next(val)), // 成功，注入值并继续 next
                err => step(() => iter.throw(err)) // 失败，抛入异常，让内部的 try/catch 处理
            );
        }
        
        // 初始启动
        step(() => iter.next(undefined));
    });
}

// --- 测试 ---
const mockFetch = (val, ms) => new Promise(r => setTimeout(() => r(val), ms));

function* myAsyncLogic() {
    console.log("Start fetching...");
    try {
        const res1 = yield mockFetch("Data 1", 1000);
        console.log(res1); // 等 1 秒后打印 "Data 1"
        const res2 = yield mockFetch("Data 2", 500);
        console.log(res2);
        return "All done";
    } catch (e) {
        console.error("Caught:", e);
    }
}

// 使用自定义运行器执行
runGenerator(myAsyncLogic).then(res => console.log(res)); 
// 依次输出: Start... -> Data 1 -> Data 2 -> All done
```

### 3.3 手写：通用柯里化 (Currying) 转换函数

**题目要求**：
实现一个工具函数 `curry`，将一个普通函数转化为可以逐步接收参数的柯里化函数。直到接收的参数总数达到原函数要求的长度，才真正执行并返回结果。

**完整答案**：
```javascript
function curry(fn) {
    // 获取目标函数所声明的形参个数 (fn.length)
    const arity = fn.length;
    
    return function curried(...args) {
        // 如果已接收的参数个数达到原函数的长度要求
        if (args.length >= arity) {
            // 真正执行原函数
            return fn.apply(this, args);
        } else {
            // 参数不够，返回一个新函数继续收集参数
            return function(...moreArgs) {
                // 将之前收集的 args 和新传入的 moreArgs 合并并递归
                return curried.apply(this, args.concat(moreArgs));
            };
        }
    };
}

// --- 测试 ---
function sum3(a, b, c) {
    return a + b + c;
}

const curriedSum = curry(sum3);

console.log(curriedSum(1)(2)(3)); // 6
console.log(curriedSum(1, 2)(3)); // 6
console.log(curriedSum(1)(2, 3)); // 6
```
