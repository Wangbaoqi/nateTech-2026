# 作用域链与闭包·TDZ - 实战面试题

## 1. 变量声明方式对比表 (面试高频)

| 特性 | `var` | `let` | `const` | `function` 声明 |
| :--- | :--- | :--- | :--- | :--- |
| **作用域** | 函数 / 全局 | 块级 / 函数 / 全局 | 块级 / 函数 / 全局 | 块级 (严格模式下) / 函数 |
| **变量提升** | 是 (初始化为 `undefined`) | 是 (但处于 TDZ, 报错) | 是 (但处于 TDZ, 报错) | 是 (初始化为完整函数对象) |
| **重复声明** | 允许 | 不允许 (SyntaxError) | 不允许 (SyntaxError) | 允许 (后覆盖前) |
| **重新赋值** | 允许 | 允许 | **不允许 (TypeError)** | 允许 (虽不推荐) |
| **全局对象属性** | 是 (在全局作用域下) | 否 | 否 | 是 (在全局作用域下) |

## 2. 经典工程陷阱

### 陷阱 1：异步 `for` 循环与 `var` 的结合

**题目**：以下代码输出什么？如何使用多种方式修改以达到输出 0,1,2 的效果？
```javascript
for (var i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 100);
}
```
**答案**：输出 3, 3, 3。

**改造方式 1 (首选)：使用 let**
```javascript
for (let i = 0; i < 3; i++) {
    setTimeout(() => console.log(i), 100);
}
```
**改造方式 2：使用 IIFE (立即执行函数) 创建新作用域**
```javascript
for (var i = 0; i < 3; i++) {
    (function(j) {
        setTimeout(() => console.log(j), 100);
    })(i);
}
```
**改造方式 3：利用 setTimeout 第三参数**
```javascript
for (var i = 0; i < 3; i++) {
    setTimeout((j) => console.log(j), 100, i);
}
```

### 陷阱 2：Class 的 TDZ 与继承的 `super()` 陷阱

**题目**：下面代码有何问题？
```javascript
class Base {
    constructor() {
        this.name = 'Base';
    }
}
class Derived extends Base {
    constructor() {
        console.log(this.name); // 报错！
        super();
    }
}
new Derived();
```
**解析**：
在继承类的构造函数中，`this` 被隔离在一个**类似于 TDZ 的状态**中。在调用 `super()` 之前，试图访问 `this` 会抛出 `ReferenceError`。这是因为在 ECMAScript 中，子类的 `this` 是由父类的构造函数 `super()` 创建和返回的，不是子类自己创建的。

## 3. 手写核心闭包工具函数

在各种大厂面试中，防抖、节流和记忆化是最考验闭包理解能力的手写题。

### 3.1 手写：Debounce (防抖)
**要求**：确保函数在最后一次触发动作后，等待一段时间再执行。支持立刻执行（`immediate` 参数）。

**完整答案**：
```javascript
function debounce(fn, wait, immediate = false) {
    let timeoutId = null;

    return function(...args) {
        const context = this;
        
        // 如果存在之前的定时器，清除它（这就是防抖的核心逻辑）
        if (timeoutId) clearTimeout(timeoutId);

        // 如果开启了 immediate，且当前没有定时器在跑，则立即执行
        const callNow = immediate && !timeoutId;
        
        // 重新设定定时器
        timeoutId = setTimeout(() => {
            timeoutId = null;
            // 如果不是 immediate 模式，则在定时器结束时执行
            if (!immediate) {
                fn.apply(context, args);
            }
        }, wait);

        if (callNow) {
            fn.apply(context, args);
        }
    };
}
```

### 3.2 手写：Throttle (节流)
**要求**：在一段时间内，无论触发多少次，函数只执行一次。要求使用时间戳与定时器结合的方式，保证第一次立即触发，且最后一次必定触发。

**完整答案**：
```javascript
function throttle(fn, wait) {
    let timeoutId = null;
    let lastTime = 0;

    return function(...args) {
        const context = this;
        const now = Date.now();
        // 计算距离下次执行还剩多少时间
        const remaining = wait - (now - lastTime);

        // 如果距离上次执行时间已经超过 wait
        if (remaining <= 0) {
            // 如果有定时器，清除
            if (timeoutId) {
                clearTimeout(timeoutId);
                timeoutId = null;
            }
            // 立即执行
            fn.apply(context, args);
            lastTime = now;
        } 
        // 否则如果在等待期间，且没有设置过定时器，就设置一个兜底的
        else if (!timeoutId) {
            timeoutId = setTimeout(() => {
                lastTime = Date.now();
                timeoutId = null;
                fn.apply(context, args);
            }, remaining);
        }
    };
}
```

### 3.3 手写：Memoize (记忆化函数)
**要求**：实现一个 `memoize` 函数，缓存传入函数的执行结果。需要支持自定义缓存键生成器 `resolver`。

**完整答案**：
```javascript
function memoize(fn, resolver) {
    // 闭包中的缓存对象
    const cache = new Map();
    
    // 包装后的函数
    const memoized = function(...args) {
        // 如果提供了 resolver，使用其计算 key，否则默认取第一个参数作为 key
        const key = resolver ? resolver.apply(this, args) : args[0];
        
        // 命中缓存则直接返回
        if (cache.has(key)) {
            return cache.get(key);
        }
        
        // 未命中则执行并将结果存入缓存
        const result = fn.apply(this, args);
        cache.set(key, result);
        
        return result;
    };
    
    // 提供一个清除缓存的方法
    memoized.cache = cache;
    
    return memoized;
}

// 测试用例
const slowAdd = (a, b) => {
    console.log(`Calculating ${a} + ${b}...`);
    return a + b;
};

// 自定义 resolver，将所有参数拼起来作为 key
const memoizedAdd = memoize(slowAdd, (...args) => JSON.stringify(args));

console.log(memoizedAdd(1, 2)); // 打印 Calculating... 返回 3
console.log(memoizedAdd(1, 2)); // 直接返回 3 (走缓存)
console.log(memoizedAdd(2, 3)); // 打印 Calculating... 返回 5
```
