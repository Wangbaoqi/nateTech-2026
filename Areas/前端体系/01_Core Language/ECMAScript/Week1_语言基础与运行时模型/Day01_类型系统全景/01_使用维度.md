# Day 01 · 类型系统全景 — 使用维度

> **今日目标**：彻底消灭「类型靠猜」的习惯，建立 JavaScript 7 种原始类型 + 1 种对象类型的精确心智模型，掌握类型判断的工程最佳实践。

---

## 一、JavaScript 类型体系全图

```
JavaScript 值
├── 原始类型 (Primitive)          ← 不可变，按值传递，存储在栈上
│   ├── undefined
│   ├── null
│   ├── boolean        (true / false)
│   ├── number         (IEEE 754 双精度浮点，含 NaN / Infinity)
│   ├── string         (UTF-16 编码序列)
│   ├── symbol         (ES2015+，全局唯一标识符)
│   └── bigint         (ES2020+，任意精度整数)
└── 对象类型 (Object)             ← 可变，按引用传递，存储在堆上
    ├── 普通对象   {}
    ├── 数组       []
    ├── 函数       function
    ├── 正则       /regex/
    ├── Date
    ├── Map / Set / WeakMap / WeakSet
    └── ...所有内置对象
```

> [!IMPORTANT]
> **核心认知**：JavaScript 中只有 8 种类型（7 原始 + Object）。所谓「数组类型」「函数类型」都是 Object 的子集，不是独立类型。

## 二、各原始类型完整使用指南

### 2.1 `undefined` — 未定义

```javascript
// 产生 undefined 的场景
let a;                          // 声明未赋值
console.log(a);                 // undefined

function foo(x) {
  return x;                     // 未传参时 x 为 undefined
}
console.log(foo());             // undefined

const obj = {};
console.log(obj.missing);      // 访问不存在属性 → undefined

function bar() {}
console.log(bar());             // 无 return 语句 → undefined

// ✅ 工程判断方式
if (value === undefined) { }    // 严格相等
if (typeof value === 'undefined') { }  // 安全（即使 value 未声明也不报错）
```

> [!WARNING]
> `undefined` 不是关键字，在非严格模式的旧引擎中可被赋值（`undefined = 1`）。始终使用 `void 0` 获取可靠的 undefined 值，或使用 `typeof` 检测。

### 2.2 `null` — 空值（主动设置的无值）

```javascript
// null 的语义：有意识地表示「此处无值」
let user = null;               // 用户尚未登录
let cache = null;              // 缓存尚未初始化

// ❌ 最大陷阱：typeof null
console.log(typeof null);      // "object" ← 历史 bug！

// ✅ 正确的 null 判断
if (value === null) { }        // 唯一可靠方式
if (value == null) { }         // 同时捕获 null 和 undefined（宽松相等）

// null 与 undefined 的语义区分
let x;           // undefined → 变量存在但未赋值（意外的无值）
let y = null;    // null     → 变量有值，值为「空」（刻意的无值）
```

### 2.3 `boolean` — 布尔值

```javascript
// 6 个假值（falsy values）
console.log(Boolean(false));     // false
console.log(Boolean(0));         // false
console.log(Boolean(-0));        // false
console.log(Boolean(0n));        // false（BigInt 零）
console.log(Boolean(''));        // false
console.log(Boolean(null));      // false
console.log(Boolean(undefined)); // false
console.log(Boolean(NaN));       // false

// 其余所有值均为真值（truthy）
console.log(Boolean([]));        // true ← 空数组是真值！
console.log(Boolean({}));        // true ← 空对象是真值！
console.log(Boolean('0'));       // true ← 非空字符串是真值！
console.log(Boolean(-1));        // true

// ✅ 工程最佳实践：使用双取反快速转换
const flag = !!someValue;
```

### 2.4 `number` — 数字

```javascript
// IEEE 754 双精度浮点，64 位
// 安全整数范围：±2^53 - 1
console.log(Number.MAX_SAFE_INTEGER);   // 9007199254740991
console.log(Number.MIN_SAFE_INTEGER);   // -9007199254740991

// 特殊值
console.log(1 / 0);           // Infinity
console.log(-1 / 0);          // -Infinity
console.log(0 / 0);           // NaN
console.log(NaN === NaN);     // false ← NaN 是唯一不等于自身的值！

// ✅ NaN 检测
console.log(Number.isNaN(NaN));         // true（推荐：严格版）
console.log(isNaN('hello'));            // true（不推荐：会先转换）
console.log(Number.isNaN('hello'));     // false（正确行为）

// 浮点精度问题
console.log(0.1 + 0.2);         // 0.30000000000000004
console.log(0.1 + 0.2 === 0.3); // false

// ✅ 精度比较
const EPSILON = Number.EPSILON;
function almostEqual(a, b) {
  return Math.abs(a - b) < EPSILON;
}
console.log(almostEqual(0.1 + 0.2, 0.3)); // true

// 整数检测
console.log(Number.isInteger(1.0));   // true
console.log(Number.isInteger(1.1));   // false
console.log(Number.isSafeInteger(9007199254740992)); // false（超出安全范围）
```

> [!TIP]
> 涉及金融计算时，永远不要用 number 直接操作货币。使用整数分（如 100 分表示 1 元）或 `BigInt`，或引入专门的精度库（如 `decimal.js`）。

### 2.5 `string` — 字符串

```javascript
// 字符串是 UTF-16 编码序列，不可变
const str = 'hello';
str[0] = 'H';                // 静默失败（非严格模式）
console.log(str);            // 'hello'（未改变）

// 长度陷阱：length 返回 UTF-16 码元数，非字符数
const emoji = '😀';
console.log(emoji.length);   // 2（代理对占 2 个码元）
console.log([...emoji].length); // 1（扩展运算符正确处理）

// 模板字符串
const name = 'World';
const greeting = `Hello, ${name}!`; // 'Hello, World!'

// 字符串方法最佳实践
const path = '  /api/users/  ';
console.log(path.trim());           // '/api/users/'
console.log(path.trimStart());      // '/api/users/  '
console.log('abc'.padStart(5, '0')); // '00abc'
console.log('abc'.padEnd(5, '-'));   // 'abc--'

// 字符串判空（工程常用）
const isEmpty = (s) => !s || s.trim().length === 0;
```

### 2.6 `symbol` — 符号（ES2015+）

```javascript
// 每次调用 Symbol() 都返回唯一值
const s1 = Symbol('description');
const s2 = Symbol('description');
console.log(s1 === s2);          // false ← 永远不相等

// 核心用途 1：对象私有属性键（防止命名冲突）
const _id = Symbol('id');
const user = {
  name: 'Alice',
  [_id]: 12345,                  // Symbol 键不会出现在常规枚举中
};
console.log(user[_id]);          // 12345
console.log(Object.keys(user));  // ['name'] ← Symbol 键被过滤
console.log(JSON.stringify(user)); // '{"name":"Alice"}' ← Symbol 键被忽略

// 核心用途 2：Well-Known Symbols（定制内置行为）
class MyArray {
  static [Symbol.hasInstance](instance) {
    return Array.isArray(instance);
  }
}
console.log([] instanceof MyArray); // true

// 迭代器协议
class Range {
  constructor(start, end) {
    this.start = start;
    this.end = end;
  }
  [Symbol.iterator]() {
    let current = this.start;
    const end = this.end;
    return {
      next() {
        if (current <= end) {
          return { value: current++, done: false };
        }
        return { value: undefined, done: true };
      }
    };
  }
}
console.log([...new Range(1, 5)]); // [1, 2, 3, 4, 5]

// 核心用途 3：全局注册表（跨模块共享）
const key = Symbol.for('app.theme');      // 全局注册/查找
const sameKey = Symbol.for('app.theme'); // 返回同一个 Symbol
console.log(key === sameKey);            // true
console.log(Symbol.keyFor(key));         // 'app.theme'
```

> [!NOTE]
> **Symbol vs String 作为对象键的本质区别**：String 键在不同模块间可能发生命名冲突；Symbol 键保证全局唯一性，是实现「协议接口」（如迭代器、自定义序列化）的标准机制。

### 2.7 `bigint` — 大整数（ES2020+）

```javascript
// 声明方式
const big1 = 9007199254740993n;           // 字面量加 n 后缀
const big2 = BigInt('9007199254740993');  // BigInt() 工厂

// 解决 Number 的精度问题
console.log(9007199254740992 === 9007199254740993);  // true（Number 精度丢失！）
console.log(9007199254740992n === 9007199254740993n); // false（BigInt 精确）

// BigInt 运算
console.log(10n + 3n);   // 13n
console.log(10n * 3n);   // 30n
console.log(10n / 3n);   // 3n（整除，截断小数）
console.log(10n % 3n);   // 1n
console.log(2n ** 100n); // 1267650600228229401496703205376n

// ❌ BigInt 不能与 Number 混合运算
console.log(1n + 1);     // TypeError: Cannot mix BigInt and other types

// ✅ 需要显式转换
console.log(1n + BigInt(1)); // 2n
console.log(Number(1n) + 1); // 2（转 Number 可能丢失精度！）

// 比较（== 允许跨类型，=== 不允许）
console.log(1n == 1);    // true（宽松相等，允许类型转换）
console.log(1n === 1);   // false（严格相等，类型不同）

// 实战：高精度 ID 处理（数据库 64 位整型）
function processUserId(id) {
  // 接收字符串形式的 64 位 ID，使用 BigInt 安全处理
  const bigId = BigInt(id);
  return bigId + 1n;
}
console.log(processUserId('9007199254740993')); // 9007199254740994n
```

## 三、类型判断完整工具箱

### 3.1 `typeof` 的真相与局限

```javascript
// typeof 返回值完整列表
console.log(typeof undefined);    // 'undefined'
console.log(typeof null);         // 'object'     ← 历史 bug！
console.log(typeof true);         // 'boolean'
console.log(typeof 42);           // 'number'
console.log(typeof 'str');        // 'string'
console.log(typeof Symbol());     // 'symbol'
console.log(typeof 42n);          // 'bigint'
console.log(typeof {});           // 'object'
console.log(typeof []);           // 'object'     ← 无法区分数组！
console.log(typeof function(){}); // 'function'   ← 函数特殊处理
console.log(typeof class {});     // 'function'   ← class 也是 function

// ✅ typeof 的最佳使用场景：检测是否声明过（不会 ReferenceError）
if (typeof someUndeclaredVar !== 'undefined') {
  // 安全访问
}
```

### 3.2 `Object.prototype.toString` — 最精确的类型检测

```javascript
const typeOf = (value) =>
  Object.prototype.toString.call(value).slice(8, -1).toLowerCase();

console.log(typeOf(null));          // 'null'
console.log(typeOf(undefined));     // 'undefined'
console.log(typeOf(42));            // 'number'
console.log(typeOf('str'));         // 'string'
console.log(typeOf(true));          // 'boolean'
console.log(typeOf(Symbol()));      // 'symbol'
console.log(typeOf(42n));           // 'bigint'
console.log(typeOf({}));            // 'object'
console.log(typeOf([]));            // 'array'      ← 正确区分！
console.log(typeOf(function(){})); // 'function'
console.log(typeOf(/regex/));       // 'regexp'
console.log(typeOf(new Date()));    // 'date'
console.log(typeOf(new Map()));     // 'map'
console.log(typeOf(new Set()));     // 'set'
console.log(typeOf(new Promise(() => {}))); // 'promise'
```

### 3.3 各场景类型判断最佳方案

```javascript
// 判断 null
const isNull = (v) => v === null;

// 判断 undefined
const isUndefined = (v) => v === undefined;
// 或：typeof v === 'undefined'（更安全，可检测未声明变量）

// 判断 null 或 undefined（nullish）
const isNullish = (v) => v == null;

// 判断数组
const isArray = Array.isArray;                    // ✅ 推荐
// Object.prototype.toString.call(v) === '[object Array]' 也可

// 判断普通对象（排除 null、数组、函数等）
const isPlainObject = (v) =>
  v !== null &&
  typeof v === 'object' &&
  Object.getPrototypeOf(v) === Object.prototype;

// 判断 Promise
const isPromise = (v) =>
  v instanceof Promise ||
  (v !== null && typeof v === 'object' && typeof v.then === 'function');

// 判断函数
const isFunction = (v) => typeof v === 'function';

// 判断整数
const isInteger = Number.isInteger;

// 完整类型检测工具
function deepTypeOf(value) {
  if (value === null) return 'null';
  if (value === undefined) return 'undefined';
  if (typeof value === 'bigint') return 'bigint';
  if (typeof value === 'symbol') return 'symbol';
  if (typeof value !== 'object' && typeof value !== 'function') {
    return typeof value;
  }
  return Object.prototype.toString.call(value).slice(8, -1).toLowerCase();
}
```

## 四、工程最佳实践 Checklist

| 场景 | ❌ 避免 | ✅ 推荐 |
|:---|:---|:---|
| 检测 null | `typeof x === 'object'` | `x === null` |
| 检测 undefined | `typeof x == 'undefined'` | `x === undefined` 或 `typeof x === 'undefined'` |
| 检测 null/undefined | `x === null \|\| x === undefined` | `x == null`（空值合并）|
| 检测数组 | `typeof x === 'object'` | `Array.isArray(x)` |
| 检测 NaN | `x === NaN` | `Number.isNaN(x)` |
| 检测整数 | 手动 `% 1 === 0` | `Number.isInteger(x)` |
| 精确类型 | `typeof` | `Object.prototype.toString.call(x)` |
| 货币计算 | `number` 直接运算 | `BigInt` 或整数分 |
| Symbol 私有属性 | 下划线前缀 `_name` | `Symbol()` 作为 key |

## 五、类型转换速查（配合 Day02 深入）

| 转换目标 | 方法 | 注意事项 |
|:---|:---|:---|
| → Number | `Number(x)`, `+x`, `parseInt(x)`, `parseFloat(x)` | `+null` = 0, `+undefined` = NaN, `+''` = 0 |
| → String | `String(x)`, `` `${x}` ``, `x.toString()` | null/undefined 调 `.toString()` 会报错 |
| → Boolean | `Boolean(x)`, `!!x` | 6 个假值外全是真值 |
| → BigInt | `BigInt(x)` | 不能转 Infinity / NaN / 非整数 Number |
